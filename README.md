# 🚀 **XE5 - Web Application**

Welcome to **XE5**, a sleek and interactive web application that offers seamless user experience. This repository contains **HTML, CSS, and JavaScript** files designed for user authentication, navigation, and dynamic interactions. ✨

![Website Banner](images/banner.jpg)   

---

## 🌟 **Features**
✅ **User Authentication** – Secure **Login** and **Registration** pages.  
✅ **Responsive Design** – Styled using multiple CSS files for dynamic adaptability.  
✅ **Interactive UI** – JavaScript-powered user interactions.  
✅ **History Tracking** – View activity through the `history.html` page.  
✅ **Social Media Integration** – Possible Facebook authentication (`fb.js`).  
✅ **Clean Project Structure** – Easy to navigate and extend.

---

## 🏗 **Project Structure**
```bash
XE5/
├── 📂 images/           # Contains image assets
├── 📝 index.html        # Home page
├── 🔑 login.html        # User login page
├── 🆕 register.html     # User registration page
├── ⏳ history.html      # History tracking page
├── 🎨 style.css        # Primary stylesheet
├── 🎨 style1.css       # Additional styles
├── 🎭 script1.js       # JavaScript for interactivity
├── 🎭 script2.js       # Additional JavaScript functions
├── 🔗 fb.js           # Facebook authentication script
└── 📜 README.md        # This fancy README! 🎉
```

## 🚀 **Getting Started**
### 🔹 **1. Clone the Repository**
```bash
git clone https://github.com/GowhithGandem46/XE5.git
cd XE5
```

### 🔹 **2. Open the Web App**
Simply **double-click** on `index.html` or open it in a browser:
```bash
firefox index.html   # For Linux
start index.html     # For Windows
open index.html      # For macOS
```

### 🔹 **3. Customize & Extend**
Want to modify the UI or functionality? Feel free to edit the HTML, CSS, and JavaScript files! 🎨
